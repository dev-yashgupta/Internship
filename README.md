## Week 1 Project

**Title:** Predicting Repeat Purchases in Online Skincare Retail

**Domain:** Beauty & Wellness / E-commerce Analytics

**Objective:** Define a business problem and propose a data science workflow to identify customers likely to make repeat purchases.

See [Week 1 project documentation](Week-01-Beauty-Wellness/README.md).

## Week 2 Project

Week 2 continues the same repeat-purchase problem and evaluates publicly discoverable data sources. The preferred candidate is REES46 Cosmetics Shop behavioural-event data, subject to verification of its current download, actual schema, stable user identifier, category coverage and use terms. UCI Online Retail II is documented only as a methodological fallback because it describes a UK giftware retailer rather than a beauty/skincare store.

See [Week 2 sourcing strategy](Week-02-Data-Sourcing/README.md).
